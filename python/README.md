# Python

**Fontes:** Hashtag Programação, com o professor João Paulo Lira (curso de Python); Estudonauta, com o professor Gustavo Guanabara (curso de Python, Mundo 0); estudo autônomo
**Data:** 07/10/2026

Python é uma linguagem de programação de alto nível, ou seja, escrita de um jeito que o ser humano consegue ler e aprender. O computador só entende linguagem de máquina (binário), então é preciso um tradutor no meio do caminho. No Python, esse tradutor é um interpretador, que lê o código e o executa. Sua sintaxe (o conjunto de regras de escrita) é limpa e focada na legibilidade.

É muito usada para automação: com poucas linhas dá para escrever scripts (roteiros em código) que fazem tarefas repetitivas no lugar de uma pessoa. As bibliotecas ampliam o que ela consegue fazer, como o `pandas` (manipulação de dados) e o `pyautogui` (controle de mouse e teclado). Também é muito usada em Segurança da Informação, justamente para automatizar tarefas.
