# Métricas de Qualidade

Data: 18/09/2026 | Fonte: Faculdade ADS

As métricas de qualidade de software se dividem em dois tipos:

- **Métricas Diretas (estruturais):** dados exatos e quantitativos do software — bugs a cada N linhas de código, tempo de resposta em milissegundos.
- **Métricas Indiretas (perceptuais/funcionais):** avaliam a agradabilidade e o impacto do software nos usuários — volume de chamados no suporte, notas de satisfação.

## A analogia dos dois olhos

Acompanhar apenas métricas diretas pode gerar um software "tecnicamente impecável" que ninguém consegue usar. Acompanhar apenas métricas indiretas gera um software intuitivo, mas que quebra no cálculo interno. É preciso usar ambas para ter visão de profundidade e equilíbrio.
