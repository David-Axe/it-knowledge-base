# Bits

## [02/09/2026] — Fonte: Estudo autônomo (mentoria com IA)

O bit é a linguagem do computador — uma linguagem de baixo nível, a linguagem binária que o computador usa. Ele é a menor unidade de informação que existe dentro do computador.

O bit não é, na sua essência, o componente elétrico em si — não é a própria tensão elétrica. O que continua sendo "um bit", independente de como ele é fisicamente implementado, é o conceito abstrato por trás: a lógica de sim ou não, positivo ou negativo, ligado ou desligado. Essa ideia abstrata pode ser representada de formas físicas diferentes — no computador, é feita através de tensão elétrica: o bit ligado transmite tensão, o bit desligado não transmite. É a combinação de vários bits que faz o computador processar os dados.

Um byte equivale a 8 bits. Por exemplo, um endereço MAC, que tem 48 bits, equivale a 6 bytes.
