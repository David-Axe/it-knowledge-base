# Merge

**03/09/2026 — Estudo autônomo (mentoria com IA)**

Termo em inglês, tradução literal: "mesclar", "unir".

Entrei em contato com esse termo durante uma mentoria com IA, ao estudar o conceito de QA (Quality Assurance) vs QC (Quality Control), no exemplo sobre code review. Não sabia o que significava, perguntei, e foi explicado assim: quando várias pessoas trabalham no mesmo software, cada uma costuma fazer suas alterações numa cópia separada do código (uma branch, ou ramificação), para não atrapalhar o trabalho de quem também está mexendo no projeto. Merge é o ato de unir essa alteração de volta ao código principal, o que vai efetivamente compor a próxima versão do software.

A razão de existir: se todo mundo editasse o mesmo código, ao mesmo tempo, no mesmo lugar, seria um caos — alterações se sobrescrevendo, conflitos constantes. Trabalhar em branches separadas e depois fazer merge é a solução para isso: cada um trabalha isolado, e a junção acontece de forma controlada.

Analogia: é como se cada marceneiro produzisse uma peça do móvel separadamente na sua bancada, e só depois todas as peças fossem encaixadas juntas no móvel final — em vez de todos mexendo na mesma peça ao mesmo tempo.
