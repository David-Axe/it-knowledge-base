# Computador

## [01/09/2026] — Fonte: Estudo autônomo (mentoria com IA)

O computador é uma máquina que recebe informações, processa essas informações e devolve um resultado.

Esse processamento consiste em realizar cálculos — matemáticos ou lógicos — sobre os dados fornecidos, em função de instruções passadas ao computador. Essas instruções podem vir de duas formas: passadas no momento pelo operador, ou já pré-estabelecidas no sistema do computador.

Essas instruções pré-estabelecidas ficam guardadas no sistema operacional, e as instruções específicas de cada tarefa (como calcular uma soma) ficam nos softwares específicos que rodam sobre esse sistema operacional.
