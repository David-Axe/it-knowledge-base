# Sistema Operacional

## [01/09/2026] — Fonte: Estudo autônomo (mentoria com IA)

As instruções pré-estabelecidas de um computador ficam guardadas no que chamamos de sistema operacional, colocadas ali pelo desenvolvedor do sistema operacional — o desenvolvedor do software.

Importante notar que nem toda instrução fica no sistema operacional. Por exemplo, as instruções de "como somar 2+2" numa calculadora não estão propriamente no sistema operacional, mas no próprio software da calculadora — mesmo que esse software esteja submetido ao sistema operacional.

Então, o que o sistema operacional realmente faz é gerenciar todos os outros softwares que existem dentro do computador, e toda a operação que o computador vai realizar. É uma espécie de gerente da empresa, fazendo uma analogia: não é ele quem propriamente faz os cálculos — o processamento dos dados — mas é ele quem gerencia esse processamento, decidindo que software vai ter precedência no uso da memória, da CPU, etc.
