# Terminal

Data: 09/09/2026 | Fonte: Estudo autônomo com IA

## O que é

O terminal é uma interface que permite ao usuário interagir com um sistema operacional através de comandos textuais.

Ele não é, por si só, uma linguagem de programação.

Um comando pode executar um programa, consultar informações, manipular arquivos ou realizar diversas outras operações.

## Terminal em segurança

O terminal é muito utilizado em segurança da informação porque permite: executar ferramentas, configurar sistemas, analisar resultados, automatizar tarefas, trabalhar remotamente e combinar diferentes ferramentas. Um exemplo prático disso é o uso do [[nmap]] via terminal, como visto no arquivo sobre [[hacker]].

## Terminal não significa baixo nível

Utilizar o terminal não significa necessariamente programar em linguagem de baixo nível ou escrever código binário.

Um comando de terminal pode simplesmente solicitar que um programa existente execute determinada operação.

Essa distinção é a mesma que sustenta a diferença entre terminal e [[interface-grafica-gui|interface gráfica]] — duas formas diferentes de acessar a mesma funcionalidade por baixo.
